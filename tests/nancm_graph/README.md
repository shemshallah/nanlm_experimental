# Persistent signed edge diagnostic (v41)
This is a component experiment within the same architecture, using the completed
v36 checkpoint, not a competing model branch. v37/v39/v40 remain untouched.
Eight cross-half rails with short and long windows retain observed association
edges across words, and subtract the document marginal at query time. Exact-key
rows avoid collisions during proposal; hashed signed geometry supplies additional
features. Fit full and exact-only transports independently on identical batches,
with the same initialization and budget. No target-derived candidate insertion.
Use the same normalized prefix law as v39. The primary diagnostic is held-out
NLL, certified top-1/5, and true vs wrong graph at matched contexts. Only after
positive results should the persistent edge signal enter the v40 recurrence.
Local executed test: 150 intervening words, exact candidate recall, bounded
eviction, snapshot/restore edge error 1.52587890625e-5 (FP32 reduction order).
The two stored channels are positive/negative components of the same lexical
projection, not independent learned S+/S- weights. Geometry currently feeds the
conserved decoder, not the recurrent triangle solver. No claim of full byte
parity for the diagnostic: integration through v39 Event is still required.
