# NaNCM structural foundation v0
Fresh reference implementation, no old model weights or gradient updates. The reference count index is built only from bounded NaNROUTER Gutenberg reference books, and is not a pretrained neural checkpoint. Every Gutenberg ID is assigned to one partition across short-story, sentence and paragraph representations. DEV uses split 7/8; split 9 is reserved. WikiText validation and chemistry are independent domain probes, not proof of absence of underlying source overlap. Google 10k lexical release is used only for lexical candidate admission.
The unified predictor implements causal local/skip/discourse and episodic evidence, bounded two-pass signed lexical reconciliation, candidate expansion, a disjoint open spelling escape, normalized prefix marginals and certified top-k when the search bound closes. Signed edges are ephemeral, factorized evidence, not a learned full 8D pair field; upper/lower lateral graph recurrence and a raw 256-byte/BPE adapter remain TODO. The fixed .20/.35 escape is an explicit untrained default. The reference is lowercase ASCII word+EOS, not a raw-byte compression model. No claims of promotion.
Run: python nancm_structural/base.py --data data --out metrics.json. See workflow for exact release assets.
