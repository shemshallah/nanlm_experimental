# Mixed word-list / sentence 300-second run (2026-11-18)

Goal: test whether a short, diverse run generalizes better than the
WikiText-2-only model.  Fresh 115,238,237-parameter model, 300-second cap,
maximum tokens at batch 32.

## Corpus

Built from three sources and shuffled at document level:

- **Word lists:** `google-10000-english` (10k common words), in 50-word list
  documents plus spelling documents (`apple: a, p, p, l, e.`).
- **Sentences:** TinyStories V2 validation text (22.5 MB).
- **Sentences:** 12 MB WikiText-103 train subset.

| Split | Documents | Tokens | Raw bytes |
|---|---:|---:|---:|
| train | 44,643 | 8,077,650 | 33,386,589 |
| valid | 471 | 87,389 | 357,826 |
| test | 498 | 89,667 | 375,869 |

Total corpus: 45,953 documents, 34,301,105 raw bytes.

## Training

- Fresh model, no WikiText-2 checkpoint
- Batch 32, ctx 512, LR 4e-4, WSD over 300 steps, warmup 30
- bf16 autocast, dense MoE dispatch, no gradient checkpointing, 8 threads
- 300-second cap

Result: **281 steps / 4,603,904 tokens / 304.9 s**, 0 non-finite skips.
That is ~15.1k tokens/s and only **0.57 epoch** over the train split.

## Evaluation

| Eval | Tokens | BPB | Top-1 |
|---|---:|---:|---:|
| Mixed held-out test | 89,666 | **1.6313** | 24.07% |
| **OOD Tiny Shakespeare** | 337,118 | **3.1724** | 9.60% |
| Official WikiText-103 test | 282,936 | 2.0843 | 13.78% |

Validation after the time cap: 1.5757 BPB, 26.14% top-1.

## Interpretation

- OOD Shakespeare improved from **4.4842 → 3.1724 BPB** versus the
  WikiText-2-only 600 s model.  It is now **below the ~3.59 BPB uniform
  baseline**, so the mixed model has some real generalization signal.
- It is **not under 1.0 BPB**.  4.6M tokens is a tiny budget; the model has
  not seen even one full epoch of the 8.08M-token mix.
- The WikiText-2-only model still wins its own held-out split (0.5183), but
  it collapses OOD (4.4842).  The mixed run trades in-domain fit for a
  modestly broader model.
- WikiText-103 test 2.0843 is a **cross-domain transfer** number, not a
  WikiText-103 benchmark.  A leaderboard claim requires training on the
  WikiText-103 train split under the official protocol, for much longer
  than 300 seconds.

## Reproduction

```sh
python z3/train_v3.py \
  --device cuda --amp --amp-dtype auto \
  --preset kaggle10m_nomtp \
  --corpus data/mixed_bins/train.bin \
  --val-corpus data/mixed_bins/valid.bin \
  --data-manifest data/mixed_bins/manifest.json \
  --batch-size 32 --ctx 512 --lr 4e-4 \
  --steps 300 --lr-total-steps 300 \
  --eval-every 100 --eval-batches 2 \
  --max-seconds 300 --no-grad-checkpoint --threads 8 \
  --moe-dense-dispatch \
  --out runs/mixed_300s
```

The corpus builder and the Molab run artifacts are in
`/marimo/z4_smoke/`; checkpoints are not committed to the repo.
