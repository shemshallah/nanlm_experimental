Accepted production: **R32** (independent TEST 24/24 books, BPB 3.212654).
This experiment adds four zero-initialized coefficients within that SAME M3
state, without a second default predictor or independent architecture.

1. The local lexical query reads the immutable, TRAIN-only R32 anchor.
2. Both local and anchor count support affect the proposed trust feedback.
3. Per-byte agreement/disagreement feeds back to the R32 distribution.
4. Zero coefficients yield **exact R32 prediction parity**; no pending target
   enters memory until after prediction, and the anchor never changes.
5. The inherited 32 optimizer groups, moments, ages, and embedded TRAIN
   background are exactly preserved in a future 36-group candidate checkpoint.
